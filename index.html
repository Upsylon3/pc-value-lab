How scoring works

Each PC gets a performance score: CPU, GPU, RAM and storage compared with a top-end yardstick PC, then weighted by how much a typical 2026 build spends on each part. RAM and storage are valued at current market prices per GB, so DDR5 counts for more than DDR4 by what it really costs. Value divides performance by price (minus an included setup), so a cheaper PC can beat a stronger one. Assumed RAM/SSD values are marked with ~.
